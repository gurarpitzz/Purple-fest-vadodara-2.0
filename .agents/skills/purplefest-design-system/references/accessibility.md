# PurpleFest Accessibility Specification (WCAG 2.1 AA+)

1. **Unmodified Preloader**: `<aside id="preloader">` remains 100% intact.
2. **Accessibility Utility Bar**:
   - Font size controls (`A-`, `A`, `A+`)
   - High Contrast mode (`theme-high-contrast`) with solid black/yellow/white AAA surfaces
   - Dyslexia-friendly reading font toggle (`font-dyslexia`)
   - 3D & Motion Pause toggle (`btn-motion-toggle`) to freeze WebGL & scroll animations on demand
   - Live Audio Narration (`btn-speak-summary`) via Web Speech API
3. **Dual Navigation (Menu-Driven + Scroll)**:
   - Top glass command bar + Fullscreen Spatial Menu Drawer + Bottom/Side Chapter Waypoint Dock allow instant 1-click access to any section without requiring long scrolling.
